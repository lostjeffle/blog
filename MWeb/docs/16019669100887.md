## io_uring - Feature - Fixed Buffer

当执行 IORING_OP_READ/IORING_OP_WRITE 操作时，对应的 @sqe->addr 描述用户态缓存的地址，如果这个 IORING_OP_READ/IORING_OP_WRITE 描述的是一个 DIRECT IO，后面执行 DIRECT IO 的时候就需要对这个用户态缓存执行 get_user_pages() 操作

```
io_uring_enter
    io_submit_sqes
        io_get_sqe // get sqe from @tail
        io_submit_sqe
            io_queue_sqe
                __io_queue_sqe
                    io_issue_sqe
                        io_write // for IORING_OP_WRITE
                            io_import_iovec
                                # opcode == IORING_OP_WRITE:
                                    import_single_range
                                        # init ITER_IOVEC type iov_iter
                                
                            f_op->write_iter()
                                # for DIRECT IO:
                                    iov_iter_get_pages
                                        # for ITER_IOVEC type iovec:
                                            get_user_pages_fast
```

上述 get_user_pages() 操作的开销会比较大，如果每次 IORING_OP_READ/IORING_OP_WRITE 操作传入的用户态缓存是固定的一块缓存，那么就可以使用 io_uring 的 fixed user buffer 特性


1. register user buffer

为了使用 fixed user buffer 特性，用户态程序首先需要调用 io_uring_register() 系统调用实现注册用户态缓存

```c
int io_uring_register(unsigned int fd, unsigned int opcode,
		void *args, unsigned int nr_args)
```

@fd 为 io_uring_setup() 返回的 io_uring 实例的 fd
@opcode 必须为 IORING_REGISTER_BUFFERS，以表示注册用户态缓存

@args 参数指向一个 iovec 数组，描述所有需要注册的用户态缓存，其中每个 iovec 描述一个需要注册的用户态缓存
@nr_args 即描述 iovec 数组的数量

io_uring_register() IORING_REGISTER_BUFFERS 过程中，传入的是一个 iovec 数组，其中每个 iovec 就描述一个需要注册的用户态缓存（fixed buffer）；这一过程中会为每个 fixed buffer 调用 pin_user_pages()，并且为每个 fixed buffer 分配一个 struct io_mapped_ubuf 结构体，通过 imu->bvec[] 数组来描述这个 fixed buffer

```
io_uring_register
    # opcode IORING_REGISTER_BUFFERS:
    io_sqe_buffers_register
        # for each iovec
            io_sqe_buffer_register
                # pin user pages of this registered user buffer (fixed buffer)
                pin_user_pages
                
                # allocate one 'struct io_mapped_ubuf' for each fixed buffer
                # and init imu->bvec[] array
                    # for each page of this fixed buffer:
                        imu->bvec[i].bv_page = 
                        imu->bvec[i].bv_len =
                        imu->bvec[i].bv_offset
```

2. setup submission queue entry

之后用户态程序在提交 IORING_OP_READ_FIXED 或 IORING_OP_WRITE_FIXED 时

- @opcode 字段必须为 IORING_OP_READ_FIXED 或 IORING_OP_WRITE_FIXED
- @buf_index 字段描述当前 read/write 操作使用的 iovec 在之前注册的 iovec 数组中的偏移
- 此时 @addr 字段描述当前操作使用的用户态缓存（iovec 描述的用户态缓存）的地址，@len 描述这个用户态缓存的大小，此时这个用户态缓存，即 (@addr, @addr+@len)，必须整个在 @buf_index 指向的用户态缓存内，而不能跨越多个注册的用户态缓存

可以看到该特性每次 IORING_OP_READ_FIXED 或 IORING_OP_WRITE_FIXED 操作只能有一个 iovec，也就是只适用于 read/write 操作

```

registered iovec array
+-----------+-----------+-----------+-----------+
|           |           |           |           |
+-----------+-----------+-----------+-----------+
                  ^
             @buf_index
             
             +----------------------------------+
 user buffer |                                  | 
             +----------------------------------+
     iov.iov_base                           iov.iov_base + iov.iov_len
                    ^               ^
                @sqe->addr      @sqe->addr + @sqe->len
```

不同于 IORING_OP_[READ|WRITE] 提交的 ITER_IOVEC 类型的 iov_iter，IORING_OP_[READ|WRITE]_FIXED 提交的是 ITER_BVEC 类型的 iov_iter，如果这个 IORING_OP\_[READ|WRITE]_FIXED 描述的是一个 DIRECT IO，后面执行 DIRECT IO 的时候，因为是 ITER_BVEC，就不再需要执行 get_user_pages() 操作，从而避免 get_user_pages() 的开销

```
# IORING_OP_WRITE_FIXED opcode
io_uring_enter
    io_submit_sqes
        io_get_sqe // get sqe from @tail
        io_submit_sqe
            io_queue_sqe
                __io_queue_sqe
                    io_issue_sqe
                        io_prep_rw
                            # for IORING_OP_WRITE_FIXED opcode:
                            req->buf_index = READ_ONCE(sqe->buf_index)
                            req->imu = ctx->user_bufs[req->buf_index]
                        
                        io_write
                            io_import_iovec
                                # opcode == IORING_OP_WRITE_FIXED:
                                    io_import_fixed
                                        # init ITER_BVEC type iov_iter
                                        iov_iter_bvec(iter, ..., imu->bvec, ...)
                                
                            f_op->write_iter()
                                # for DIRECT IO:
                                    iov_iter_get_pages
                                        # for ITER_BVEC type iovec:
                                            get_page
```


3. unregister user buffer

此外也可以调用 io_uring_setup() 注销之前注册的用户态缓存，此时 @opcode 必须为 IORING_UNREGISTER_BUFFERS

此时 io_uring_setup() 的 @args 与 @nr_args 必须全部为 0，此时会注销之前注册的所有用户态缓存
