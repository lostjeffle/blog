## libfuse - fuse session - fuse over iouring


## worker population

主进程创建出第一个 worker 线程以后，也一样进入睡眠状态

```
# main
se = fuse_session_new(..., &lo_ops, ...)

fuse_session_mount(se, mntpoint)
    fuse_kern_mount
        fuse_mount_sys
            fd = open("/dev/fuse", ...)
            mount(2)
    
fuse_session_loop_mt(se, &config)
    fuse_session_loop_mt_312
        fuse_loop_start_thread
            # create first worker
            fuse_start_thread
                pthread_create(..., fuse_do_work)
            mt->numavail ++
            mt->numworker ++
        
        # wait here until exited
```

第一个创建出来的 worker 线程会处理 FUSE_INIT 请求，在 iouring 模式下就会创建所有的 ring 和对应的 ring worker；这个 worker 线程会等待所有 ring worker 都初始化完成以后再发送 FUSE_INIT reply

这里需要注意的是，ring worker 在创建出来后只会向内核注册所有的 (FUSE_IO_URING_CMD_REGISTER) ring entry，之后需要等待所有 ring worker 都完成对应 ring 的 ring entry 的注册以后，每个 ring worker 再继续执行 while loop，即等待内核下发 FUSE 请求并处理

```
# FUSE_INIT worker
fuse_do_work
    # receive FUSE_INIT
    _do_init
        # if FUSE_OVER_IO_URING detected:
        fuse_uring_start
            # init fuse ring
            fuse_create_ring
            
            # create ring worker
            fuse_uring_start_ring_threads
                                                    # uring worker
                                                    fuse_uring_thread
                                                        fuse_uring_init_queue
                                                            # setup each queue entry with
                                                            # FUSE_IO_URING_CMD_REGISTER
                                                            
                                                            # submit all FUSE_IO_URING_CMD_REGISTER entries
                                                            io_uring_submit
            
            # wait until all ring workers
            # are successfully created
        
        # reply FUSE_INIT
        
        fuse_uring_wake_ring_threads
            # wakeup all ring workers
            sem_post(&ring->init_sem)
                                                        while !se->mt_exited:
                                                            # wait for coming requests
                                                            io_uring_submit_and_wait
                                                                
                                                            # once received request
                                                            fuse_uring_queue_handle_cqes
                                                                # for each cqe (fuse request):
                                                                    fuse_uring_handle_cqe
                                                                        fuse_session_process_uring_cqe
                                                                            # handle the request
```

一旦所有 uring worker 都准备就绪之后，内核 fuse 就会切换为 uring 模式，此后请求都是通过 uring 通道发送给 uring worker 线程，此时处理 FUSE_INIT 请求的普通 worker 线程就会一直陷入 idle 状态


## exit

> first uring worker receives -ENOTCONN

当挂载被 umount 掉的时候，会收割所有 uring entry，并以 -ENOTCONN 返回

```
# kernel
fuse_abort_conn
    fuse_uring_abort
        fuse_uring_stop_queues
            # for each uring queue:
                fuse_uring_teardown_entries
                    # for each ring entry:
                        fuse_uring_entry_teardown
                            cmd = ent->cmd
                            io_uring_cmd_done(cmd, -ENOTCONN, 0)
            
```

uring worker 线程在收到这些 uring entry 的完成事件的时候，一旦收到 -ENOTCONN 错误（即挂载被 umount 掉或者 abort 掉），就会置位 se->mt_exited 以通知主线程和其他 uring worker 线程

```
# uring worker
fuse_uring_thread
    while !se->mt_exited:
        # wait for coming requests
        io_uring_submit_and_wait
            
        # once received request
        fuse_uring_queue_handle_cqes
            # for each cqe (fuse request):
                if cqe->res == -ENOTCONN:
                    return -ENOTCONN
        
        # once -ENOTCONN received:
        fuse_session_exit
            se->mt_exited = 1
            sem_post(&se->mt_finish)
```


> main thread

主线程在创建完第一个普通 worker 线程（也就是处理 FUSE_INIT 请求的那个 worker 线程）以后就会进入睡眠状态，直到 uring worker 线程发现挂载已经被 umount 掉之后将 mt_exited 置位，并唤醒主线程

主线程先将不多的几个普通 worker 线程（例如处理 FUSE_INIT 请求的那个 worker 线程，这个 worker 线程在处理完 FUSE_INIT 请求之后就一直处于 idle 状态）退出掉

```
# main
fuse_session_loop_mt(se, &config)
    fuse_session_loop_mt_312
        fuse_loop_start_thread
            # create first worker
            fuse_start_thread
                pthread_create(..., fuse_do_work)
        
        # wait here until exited
        while !se->mt_exited:
            sem_wait(&se->mt_finish)
            
        # woken up
        
        # cancel and cleanup normal worker thread
        for each worker thread:
            pthread_cancel 
        for each worker thread:
            pthread_join
```

之后主线程需要通知其他 uring worker 线程开始退出，但是因为 uring worker 经由 uring_enter() 陷入内核态，因而置位 se->mt_exited 并不足以通知到陷入内核态的 uring worker 线程

因而每个 uring worker 线程在创建的时候都注册了一个 eventfd，同时注册了一个 uring sqe 来监听这个 eventfd

```
# uring worker
fuse_uring_thread
    fuse_uring_init_queue
    queue->eventfd = eventfd(0, EFD_CLOEXEC)
        
        fuse_uring_prepare_fetch_sqes
            # register one IORING_OP_POLL_ADD for queue->eventfd
            io_uring_prep_poll_add(sqe, queue->eventfd, POLLIN)
            io_uring_submit
```

回到主线程，当主线程被唤醒的时候，就会对每个 uring worker 的 eventfd 执行写入操作

```
# main thread
fuse_session_loop_mt(se, &config)
    fuse_session_loop_mt_312
        
    # woken up
    
    fuse_uring_stop
        fuse_session_destruct_uring
            # for each uring queue:
                write(queue->eventfd, ...)
                pthread_join(queue, ...)
                
```

这样通过 iouring 监听这个 eventfd 的 uring worker 就会收到一个 cqe 并从内核态被唤醒返回到用户态，当发现这个 cqe 是来自 eventfd 的时候，就知道是挂载被 umount 掉了，此时 uring worker 线程就会进入退出流程

```
# uring worker
fuse_uring_thread
    while !se->mt_exited:
        # wait for coming requests
        io_uring_submit_and_wait
            
        # once received request
        fuse_uring_queue_handle_cqes
            # for each cqe (fuse request):
                if this cqe is for eventfd:
                    return -ENOTCONN
        
        # once -ENOTCONN received:
        fuse_session_exit
            se->mt_exited = 1
            sem_post(&se->mt_finish)
```
